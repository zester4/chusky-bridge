# Skills

Skills are instruction packages for people and AI agents working on this repository. Each skill has
a `SKILL.md` with the workflow and rules, and a `references/` folder with detail to load when needed.

| Skill | Use it when |

| [chusky-bridge](chusky-bridge/SKILL.md) | Building, extending, connecting systems to, or operating Chusky Bridge |
